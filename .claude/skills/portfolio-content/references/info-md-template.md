# info.md template

Status convention:
- The body of `info.md` holds **confirmed facts only**.
- Pending items go under **Open questions**.
- Declined or not-applicable items go under **Not included**, so they are not asked again.

Only the main session edits `info.md`, and only after the owner confirms.
